# CRM Ginco

App do CRM do Luiz: abre no navegador e instala na tela de início (iPhone, iPad e PC).

- Login com Google e dados no Firebase (Firestore), protegidos pelas regras do projeto.
- `mtb/`: base pública de empresas (Receita Federal) usada na prospecção.
- Nenhum dado de cliente fica neste repositório.
